Add syntax highlighting. `@oito2/ui-syntax` gets `Highlighter` (highlight.js 11.12 with the same 27 default languages as oito2_ui in `defaultLanguages`, language aliases in any letter case, optional detection and extra grammars), `HighlighterTheme.fromPalette`, `scopeRoles` and `roleOfScope`, which color highlight.js scopes with the syntax roles of the active scheme, and `CodeBlock`, a read-only code block with optional line numbers and a copy button in JetBrains Mono.
