Fix the Tauri integration and make the satellite packages share one copy of `@oito2/ui`. `@oito2/ui` becomes a peer dependency of every other package, and `@tauri-apps/api`, `@tauri-apps/plugin-dialog` and `@tauri-apps/plugin-fs` peer dependencies of `@oito2/ui-files`, `@oito2/ui-window` and `@oito2/ui-settings`, so the app picks their versions; the published packages no longer carry the test goldens. `@oito2/ui-files`: the Tauri drop target converts drag-drop positions to CSS pixels only on Windows, where wry reports physical pixels, so drops on HiDPI Linux and macOS land on the zone; a file whose size can't be read is refused with the new `unreadable` reason (`fileUnreadable` string) instead of failing the whole batch, the count limit is checked before the size, drag-and-drop and `FileUpload` failures are reported instead of left unhandled, previews follow `showPreviews`, the drop zone's accessible name no longer repeats the "Choose files" badge, MIME-only `accept` groups filter the native chooser through the extension table (`extensionsForMimeType`) and the table covers more types. `@oito2/ui-window`: `initWindow` takes a `signal`, returns the live controller when called again for the same window and rejects with a clear message without the plugin; `dispose()` clears the `data-oito2-*` attributes; a focus change no longer discards a state read in flight; `showMenu()` without a position opens under the pointer; `CommandError` and `isCommandError` type the plugin rejections. `@oito2/ui-settings`: `isRawSettings` validates the plugin payload, failed reads warn once instead of failing silently, and `CommandError` types the rejections. `@oito2/ui-themes`: `presetSchemeName(preset, { highContrast })` returns the `data-oito2-scheme` value of a preset. Rust: `set_decoration_mode` and `show_window_menu` wait for the main-thread work and reject with the real error, decoration modes switch cleanly on Linux (a visible window is refused), destroyed windows are forgotten, a relative `XDG_CONFIG_HOME` is ignored and the settings plugin's error kinds are `unsupported` and `internal`.
