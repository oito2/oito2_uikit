Add the oito2 foundation: design tokens (radii, spacing, sizes, accent, neutral and status colors, the Inter type scale) in TypeScript and as CSS custom properties (`@oito2/ui/styles.css`, `tokens.css`, `density.css`, `base.css`, `fonts.css`), WCAG contrast helpers, platform and desktop environment detection, window button layout parsers for GNOME, KDE and Xfce, system settings with `SystemScope`, English and Brazilian Portuguese strings with `LocaleProvider`, and locale-aware formatting of byte sizes, compact numbers and relative times.
