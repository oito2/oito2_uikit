## Default Permission

Lets the webview read the system settings (desktop session, window button layout, accent color and contrast).

#### This default permission set includes the following:

- `allow-read-settings`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`oito2-settings:allow-read-settings`

</td>
<td>

</td>
</tr>

<tr>
<td>

</td>
