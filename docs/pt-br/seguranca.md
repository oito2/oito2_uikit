# Política de Segurança

🌐 **Idioma:** [English](../../SECURITY.md) · Português

## Versões suportadas

O oito2_uikit é lançado com uma única versão para todos os pacotes npm e plugins Rust. Antes da 1.0, só a linha minor mais recente recebe correções de segurança.

| Versão | Suportada |
| ------ | --------- |
| 0.1.x  | ✅        |

## Como relatar uma vulnerabilidade

Relate vulnerabilidades **em privado**, nunca por uma issue, pull request ou discussão pública.

Use o relato privado de vulnerabilidades do GitHub: abra a [aba **Security**](https://github.com/oito2/oito2_uikit/security) do repositório e escolha **Report a vulnerability**.

## O que incluir

- O pacote (`@oito2/*`) ou crate (`tauri-plugin-oito2-*`) afetado e a versão.
- O sistema operacional e o WebView (WebKitGTK, WebView2 ou WKWebView), quando for relevante.
- Os passos para reproduzir, uma prova de conceito se você tiver, e o impacto esperado.

## O que esperar

Os mantenedores confirmam o recebimento no próprio aviso privado, investigam o problema e mantêm você informado por lá. Quando a correção estiver pronta, ela sai numa nova versão e o aviso é publicado, com crédito a você, a menos que prefira ficar anônimo.
