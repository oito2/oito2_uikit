# Security Policy

🌐 **Language:** English · [Português](docs/pt-br/seguranca.md)

## Supported Versions

oito2_uikit is released with one version for every npm package and Rust plugin. Before 1.0, only the latest minor line receives security fixes.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a Vulnerability

Please report vulnerabilities **privately**, never through a public issue, pull request or discussion.

Use GitHub's private vulnerability reporting: open the repository's [**Security** tab](https://github.com/oito2/oito2_uikit/security) and choose **Report a vulnerability**.

## What to Include

- The affected package (`@oito2/*`) or crate (`tauri-plugin-oito2-*`) and its version.
- The operating system and WebView (WebKitGTK, WebView2 or WKWebView), when relevant.
- Steps to reproduce, a proof of concept if you have one, and the impact you expect.

## What to Expect

The maintainers acknowledge the report in the same private advisory, investigate it, and keep you informed there. When a fix is ready, it is released as a new version and the advisory is published, crediting you unless you prefer to stay anonymous.
